# 📁 Rename File with OS

A simple Python script that demonstrates how to **rename files and directories** using the `os` module. This project was built to practice file handling and automation using Python's built-in operating system interface.

---

## 🎯 Features

- ✅ Rename a single file using `os.rename()`
- ✅ Rename multiple files in a directory using a loop
- ✅ Error handling for missing files
- ✅ Simple and practical automation example

---

## 🛠️ Technologies Used

- Python 3
- OS Module (`os.rename`)

---

## 🧠 Concepts Practiced

- File handling with the `os` module
- Renaming files programmatically
- Error handling (`try-except`)
- Working with file paths

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abdul-rafay-dev0/Rename-file-wtih-OS.git
   ```

   ```bash
   cd Rename-file-wtih-OS
   ```

